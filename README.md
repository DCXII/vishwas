# VISHWAS - Blockchain-Based Identity Verification System

![VISHWAS Logo](https://img.shields.io/badge/VISHWAS-Blockchain%20Identity-blue?style=for-the-badge)

## Project Overview

VISHWAS (Verifiable Identity System with Hyperledger and Secure Authentication) is a blockchain-based identity verification system that combines biometric authentication with distributed ledger technology. Built on Hyperledger Fabric, it provides secure, transparent, and tamper-proof identity management for modern applications.

## Key Features

- Biometric Authentication: Simulated biometric scanning for enhanced security  
- Blockchain Integration: Hyperledger Fabric for immutable record keeping  
- Multi-Role Support: Patient, Doctor, Authority, and Admin roles  
- JWT Security: Token-based authentication system  
- Modern UI: React-based responsive frontend with Material-UI  
- Data Integrity: Cryptographic hashing and blockchain verification  

## Technology Stack

- Frontend: React.js, Material-UI, Axios  
- Backend: Node.js, Express.js, MongoDB  
- Blockchain: Hyperledger Fabric, Go Chaincode  
- Authentication: JWT, bcrypt  
- Database: MongoDB  
- Containerization: Docker
